# Шрифти DAKH

Акцидентний шрифт бренду — **Hajdamaka** (AndrijType). Це комерційна гарнітура; файли в репозиторій не кладемо.

Щоб підключити ліцензійний webfont, покладіть `Hajdamaka.woff2` у цю теку. CSS уже шукає його першим у стеку `--font-display`. Доки файла немає, заголовки рендеряться **Cormorant Garamond** (кирилиця, редакційний характер).

Інтерфейсний шрифт — Montserrat (Google Fonts): Regular, Medium, SemiBold, Medium Italic.
