# DAKH

Фронтенд-прототип готелю і ресторану **DAKH** у Мигові.

Сайт: https://anastasiia1002.github.io/dakh/

Зібраний фронтенд лежить у корені репозиторію (`index.html`, `assets/`), бо GitHub Pages зараз публікує гілку `main`.

```bash
cd frontend && npm install && npm run build && cp -a dist/. ..
```

```bash
cd frontend && npm install && npm run dev
```

Локально Vite відкриває додаток з бази `/dakh/` (як на GitHub Pages).
