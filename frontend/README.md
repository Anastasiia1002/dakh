# dakh

Прототип фронтенду для **Sunny Park** — готельного комплексу в Мигові.

Зараз у репозиторії лише клієнтська частина: каталог номерів і таунхаусів, SPA, ресторан LA Terrace і сценарій бронювання з тестовою наявністю. Бекенду ще немає — заявки зберігаються в `localStorage`.

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Збірка: `npm run build`.

## Що вже є

- головна з пошуком дат
- каталог проживання та картки об’єктів
- SPA з тарифами для гостей і відвідувачів
- сторінка ресторану
- бронювання: дати → житло → контакт → підтвердження
- контакти, мапа, FAQ

Копірайт і ціни звірені з публічним сайтом [sunnypark.com.ua](https://sunnypark.com.ua/), тексти написані заново.
